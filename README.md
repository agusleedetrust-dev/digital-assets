## 🌐 Cara Deploy ke GitHub & Vercel (Gratis & Cepat):

### Langkah 1: Buat Repositori di GitHub
1. Buka [github.com](https://github.com) dan login ke akun Anda.
2. Klik tombol **New Repository**.
3. Beri nama repositori: `digital-assets` (pilih *Public*).
4. Klik **Create repository**.

### Langkah 2: Upload Project ke GitHub
Buka terminal / CMD di folder `E:\PROJECT DARI FOLDER DOWNLOAD\digital-assets`, lalu ketik perintah berikut:
```bash
git init
git add .
git commit -m "feat: inisialisasi toko digital assets 50 software open source"
git branch -M main
git remote add origin https://github.com/USERNAME-GITHUB-ANDA/digital-assets.git
git push -u origin main
```
*(Atau cukup klik ganda file `update-ke-github.bat` yang sudah disediakan di folder ini).*

### Langkah 3: Sambungkan ke Vercel
1. Buka [vercel.com](https://vercel.com) dan login menggunakan akun GitHub Anda.
2. Klik tombol **Add New... $\rightarrow$ Project**.
3. Pilih repositori **`digital-assets`** dari daftar GitHub Anda.
4. Klik tombol **Deploy** (tanpa perlu ubah setting apa pun).
5. Dalam waktu 10-20 detik, website Anda langsung online dengan alamat:  
   👉 `https://digital-assets-xxxx.vercel.app`
